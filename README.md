# NovaStack Studio Website

Static responsive website built with only HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser.

## Customize
- Company email: edit `hello@novastack.studio` in `index.html`
- Services/projects: edit the HTML content
- Colors/fonts/layout: edit `css/style.css`
- Interactions: edit `js/script.js`

No build tools or framework are required.
